# האגר – ארץ

אתר הסרט ״האגר – ארץ״ בבימוי שמואל ברו. עמוד אחד, בלי תלויות בנייה. אפשר לפרסם כמו שהוא, למשל ב-GitHub Pages.

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html` | כל האתר: HTML, CSS ו-JavaScript |
| `img/` | פריימים מהסרט ותמונת הבמאי, בפורמט WebP |

## עדכונים שגרתיים

בראש הסקריפט שבתחתית `index.html`:

- **טריילר:** `TRAILER_URL`, קישור YouTube או Vimeo. כל עוד הוא ריק, הכפתור מציג ״הטריילר בקרוב״.
- **הקרנות:** הרשימה `SCREENINGS`. לכל הקרנה: `date`, `city`, `venue`, ו-`url` לרכישה או `soldOut:true`. הקרנות שעברו נעלמות לבד.
- **גלריה:** הרשימה `GALLERY`. כל פריט הוא שם קובץ (בלי סיומת) וכיתוב.

## תמונות

שמות הקבצים קבועים: `<שם>-960.webp` לגרסה הקטנה ו-`<שם>-2048.webp` לגדולה. `director-800.webp` היא תמונת הבמאי.

## תצוגה מקדימה בשיתוף (וואטסאפ, פייסבוק)

התמונה שמופיעה כשמשתפים קישור היא `img/share-poster.jpg` (1200×630). האייקונים: `img/favicon.png` ו-`img/apple-touch-icon.png`.

תגיות השיתוף בראש `index.html` מפנות לכתובת המלאה של האתר, כרגע `https://nfed.github.io/hager/`. כשהאתר עובר לדומיין משלו, צריך להחליף את הכתובת הזו בכל המופעים שלה (`canonical`, `og:url`, `og:image`). וואטסאפ שומר תצוגות בזיכרון, אז לבדיקה כדאי לשלוח קישור שלא נשלח קודם, למשל עם `?v=2` בסוף.

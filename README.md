# האגר – ארץ

אתר הסרט ״האגר – ארץ״ בבימוי שמואל ברו. עמוד אחד, בלי תלויות בנייה. אפשר לפרסם כמו שהוא (למשל ב-GitHub Pages).

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html` | כל האתר: HTML, CSS ו-JavaScript |
| `img/` | פריימים מהסרט ותמונת הבמאי, בפורמט WebP |

## עדכונים שגרתיים

בראש הסקריפט שבתחתית `index.html`:

- **טריילר:** `TRAILER_URL`, קישור YouTube או Vimeo. כל עוד הוא ריק, הכפתור מציג ״הטריילר בקרוב״.
- **הקרנות:** הרשימה `SCREENINGS`. לכל הקרנה: `date`, `city`, `venue`, ו-`url` לרכישה או `soldOut:true`. הקרנות שעברו נעלמות לבד.
- **גלריה:** הרשימה `GALLERY`. כל פריט הוא שם קובץ (בלי סיומת) וכיתוב.
